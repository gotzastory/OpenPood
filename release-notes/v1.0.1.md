# OpenPood v1.0.1

## ระบบอัปเดตในแอป

- เช็กเวอร์ชันใหม่อัตโนมัติหลังเปิดแอป และทุก 6 ชั่วโมง พร้อมแจ้งเตือนเมื่อมีอัปเดต
- เพิ่มส่วนอัปเดตใน Settings: แสดงเวอร์ชันปัจจุบัน/ใหม่ รายละเอียด release และความคืบหน้าดาวน์โหลด
- ผู้ใช้เลือกดาวน์โหลดเอง แล้วกด Restart & Update เมื่อต้องการติดตั้ง ปิดหน้าหรือออกจากแอปจะไม่ติดตั้งเอง
- กันการติดตั้งขณะเริ่มอัดเสียง อัดเสียง ถอดเสียง หรือวางข้อความ พร้อม retry เมื่อเช็ก/ดาวน์โหลดไม่สำเร็จ
- ใช้ GitHub Releases เป็น update feed สำหรับ Windows NSIS พร้อม installer, blockmap และ latest.yml
- อัปเดต dependency security patches ที่อยู่ใน semver range เดิม

## สำหรับผู้ใช้ OpenPud / OpenPood รุ่นก่อนหน้า

1. ดาวน์โหลด OpenPood-Setup-1.0.1.exe จาก release นี้
2. ปิดแอปเดิมจาก tray แล้วเปิด installer โดยไม่ต้องถอนแอปเดิมก่อน
3. รุ่นนี้คง NSIS upgrade identity เดิมและมีระบบคัดลอกข้อมูล OpenPud ไป OpenPood โดยเก็บต้นฉบับไว้
4. หลังติดตั้ง v1.0.1 แพตช์ในอนาคตจะเช็กและดาวน์โหลดได้จาก Settings → อัปเดต OpenPood

## Verification

- Unit tests และ TypeScript/Vite build ผ่านก่อนเผยแพร่; CI ตรวจ installer, blockmap และ metadata version ก่อน publish
- การติดตั้งทับ OpenPud, microphone/hotkey/Escape/focus/clipboard/paste/tray/quit และการอัปเดตจากรุ่น A ไป B ยังต้องตรวจบน Windows จริง
- Installer ยังไม่มี Windows code-signing certificate; updater ตรวจ checksum ของไฟล์ดาวน์โหลด แต่ยังไม่มี publisher signature verification
