# OpenPood 1.0.0 — New brand, new design

OpenPud เปลี่ยนชื่อเป็น **OpenPood** พร้อม redesign Dashboard, Onboarding และ Recording widget และเพิ่ม ElevenLabs สำหรับถอดเสียง

## ฟีเจอร์ที่เพิ่มใหม่

- **ElevenLabs Speech to Text**: เลือก Scribe v2 (ค่าเริ่มต้น) หรือ Scribe v1 ได้จาก Settings และเลือก ElevenLabs ได้ตั้งแต่ Onboarding
- **Onboarding 5 ขั้นตอน**: เริ่มต้น → เลือก provider / API key → เลือกไมค์พร้อม waveform → ตั้ง hotkey → ทดลองพูดแล้ววางข้อความในช่องทดสอบ
- **ตั้ง hotkey จากหน้า Home**: เปิดหน้าต่างตั้งปุ่มลัดของ Dictate และ Translate ได้โดยตรง
- **ย้ายข้อมูลจาก OpenPud อัตโนมัติ**: คัดลอก Settings, API key ที่เข้ารหัส, History และ Dictionary ไปยัง OpenPood โดยเก็บต้นฉบับไว้ และไม่เขียนทับข้อมูล OpenPood ที่มีอยู่

## Redesign ใหม่

- **Brand ใหม่**: ชื่อ OpenPood, logo, symbol, tray icon และ Windows application icon ชุดใหม่
- **Dashboard**: sidebar สีขาวพร้อมเมนูภาษาไทย, workspace โทน Light Blue และ Blue accent; หน้า Home เน้น Dictate / Translate และแสดงสถิติการใช้งานแยกชัดเจน
- **Settings**: จัดกลุ่มการตั้งค่าใหม่ พร้อม provider / model controls และสถานะของฟีเจอร์ที่ใช้ได้กับ provider ที่เลือก
- **History / Dictionary**: ปรับรายการและปุ่มให้เข้ากับดีไซน์ใหม่
- **Onboarding**: หน้าต้อนรับโทน Ink, ปุ่ม Blue และ progress 5 ขั้นแบบไม่มี sidebar
- **Recording widget**: pill สีเข้มโปร่งแสงพร้อม symbol ใหม่, waveform และสถานะกำลังถอดเสียง / ไม่ได้ยินเสียง
- **Typography / Motion**: ใช้ฟอนต์ Kanit ที่ bundle มากับแอป และปรับ animation ของหน้าเริ่มต้น

## ข้อควรรู้ก่อนอัปเดต

- ElevenLabs รองรับ **ถอดเสียงเท่านั้น** ใน OpenPood; AI polish และ Translate ต้องเลือก provider อื่น ส่วน Dictionary correction rules ยังทำงานในเครื่อง
- API key ยังคงเข้ารหัสผ่าน Windows DPAPI / Electron safeStorage; เสียงและข้อความส่งไปยัง provider ตามการตั้งค่า ประวัติเก็บในเครื่อง
- คง NSIS upgrade identity เดิมสำหรับการอัปเดตจาก OpenPud
- ยังต้องตรวจ microphone, hotkey, Escape, focus guard, clipboard / paste และ tray / quit บน Windows จริงก่อนยืนยันพร้อมใช้งาน production

การเปลี่ยนแปลงอิง commits หลัง `v0.4.0` ถึง release `v1.0.0`.
