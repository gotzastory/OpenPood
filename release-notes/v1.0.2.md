# OpenPood v1.0.2

## ใหม่

- เพิ่ม Dark theme ใน Dashboard ค่าเริ่มต้นตามการตั้งค่าของ Windows และมีปุ่มสลับธีมที่ sidebar โดยบันทึกการเลือกไว้
- เพิ่มโมเดลถอดเสียงใหม่ใน OpenRouter: AssemblyAI Universal 3.6 Pro, ElevenLabs Scribe v2 และ ElevenLabs Scribe v2 Medical
- เพิ่มไฟล์ LICENSE (MIT)

## ปรับปรุง

- อัปเดตไอคอน/โลโก้ OpenPood และปรับโลโก้ใน sidebar ให้เข้ากับธีม Dark
- ปรับปรุงความเสถียรของการอัดเสียงและการวางข้อความ:
  - widget กลับมาทำงานได้เองหลังหน้าต่าง renderer ค้างหรือโหลดไม่สำเร็จ หรือคำสั่ง hotkey ไม่ตอบกลับ
  - จดจำปลายทางที่จะวางข้อความตั้งแต่ตอนกดเริ่มอัด และตรวจ focus กับ clipboard ก่อนวาง ถ้าเปลี่ยนแอประหว่างรอ ข้อความจะอยู่ใน clipboard แทนการวางผิดที่
- การเรียก API ของ provider มี timeout และจำกัดขนาด response พร้อมข้อความ error ภาษาไทยที่อ่านเข้าใจได้ง่ายขึ้น
- ประวัติการถอดเสียงบันทึกแบบ atomic เพื่อลดโอกาสข้อมูลเสียหายเมื่อปิดแอปกะทันหัน
- ไม่บันทึก API key เมื่อระบบเข้ารหัสของ Windows ใช้งานไม่ได้ เพื่อความปลอดภัย

## สำหรับผู้ใช้ OpenPood v1.0.1

- ถ้าติดตั้ง v1.0.1 แล้ว ไปที่ Settings → อัปเดต OpenPood แล้วกดดาวน์โหลดได้เลย
- หรือดาวน์โหลด OpenPood-Setup-1.0.2.exe จาก release นี้ แล้วติดตั้งทับได้โดยไม่ต้องถอนแอปเดิมก่อน

## Verification

- Unit tests (147 รายการ) และ TypeScript/Vite build ผ่าน
- ตรวจ installer, blockmap, latest.yml และ SHA-512 ของ update artifacts ด้วย `scripts/verify-update-artifacts.cjs` ผ่าน
- ยังต้องตรวจบน Windows จริง: microphone, hotkey, Escape, focus guard, clipboard/paste, tray และ quit
- Installer ยังไม่มี Windows code-signing certificate
