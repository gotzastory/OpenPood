# OpenPood v1.0.3

## ใหม่

- เพิ่มหน้า "แอป" ใน Dashboard สำหรับตั้งค่าโปรไฟล์รายแอป: เลือกเปิด/ปิด AI polish และกำหนดโทนข้อความแยกตามโปรแกรมที่กำลังพิมพ์อยู่ โปรไฟล์จะมีผลเหนือการตั้งค่า AI polish หลัก และบันทึกทันทีโดยไม่ต้องกด Save
- แสดงเครดิตคงเหลือของ OpenRouter ที่ sidebar ของ Dashboard (แสดงเมื่อเลือก provider เป็น OpenRouter)
- เพิ่มโมเดลถอดเสียงใหม่ใน OpenRouter: Mistral Voxtral Small Transcribe 3 และ Voxtral Mini Transcribe 3

## แก้ไข

- แก้ปัญหาข้อความไม่ถูกวางอัตโนมัติ เมื่อ clipboard มีข้อมูลที่คัดลอกมาจาก Chrome, Edge หรือแอป Electron

## สำหรับผู้ใช้ OpenPood v1.0.2

- ไปที่ Settings → อัปเดต OpenPood แล้วกดดาวน์โหลดได้เลย
- หรือดาวน์โหลด OpenPood-Setup-1.0.3.exe จาก release นี้ แล้วติดตั้งทับได้โดยไม่ต้องถอนแอปเดิมก่อน

## Verification

- Unit tests (155 รายการ) และ TypeScript/Vite build ผ่าน
- ตรวจ installer, blockmap, latest.yml และ SHA-512 ของ update artifacts ด้วย `scripts/verify-update-artifacts.cjs` ใน CI
- ยังต้องตรวจบน Windows จริง: microphone, hotkey, Escape, focus guard, clipboard/paste, tray และ quit
- Installer ยังไม่มี Windows code-signing certificate
